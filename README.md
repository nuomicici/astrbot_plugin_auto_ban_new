# AstrBot 进群禁言插件

一个功能完善的 QQ 群新成员管理插件，通过自动禁言和递进式监控机制，引导新成员先阅读群规再发言，有效防止入群刷屏、打广告等行为。

## 功能特性

### 核心功能
- **新成员自动禁言** - 成员入群时自动执行初始禁言，并发送欢迎消息引导阅读群规
- **多种验证考核模式** - 支持 4 种解禁验证模式：
  - **指定关键词/固定语句**：发送包含指定关键词的消息即解禁
  - **加减算术计算**：系统随机生成加减算式，回复正确数字解禁
  - **乘除算术计算**：系统随机生成乘法或整除算式，回复正确数字解禁
  - **自定义问答/诗词填空**：支持在 WebUI 自定义题库（如诗词名句、群规问答），入群随机抽题考核，回答正确即解禁
- **戳一戳快速解禁** - 可选支持戳一戳 Bot 快速解除监听
- **递进式禁言机制** - 对未解禁成员的违规消息执行递进式禁言（可配置 4 个阶段时长）
- **违规消息撤回** - 可选自动撤回未按要求发送的消息（仅对监听中成员生效）
- **自动踢出** - 违规次数达到阈值后自动移出群聊
- **退群自动清理** - 成员主动退群或被踢出后自动从监控列表移除

### 管理功能
- **分群独立配置** - 每个群聊可单独配置禁言时长、提示消息等参数
- **WebUI 可视化管理** - 现代化 Web 界面，支持实时查看和编辑配置
- **监控用户管理** - 查看当前监控用户列表，支持手动移除监控
- **群列表管理** - 自动获取 Bot 管理的群聊，显示群头像、群名、Bot 权限
- **定期巡检** - 后台定时检查监控用户是否仍在群内，自动清理无效数据

### 数据存储
- **SQLite 数据库** - 使用轻量级数据库持久化存储配置和监控数据
- **异步 I/O** - 全异步数据库操作，不阻塞事件循环
- **数据安全** - 自动数据库初始化、事务保护、并发锁控制

## 系统要求

- **AstrBot** >= 4.9.2
- **平台支持** - 仅支持 OneBot v11 协议（aiocqhttp）
- **Bot 权限** - 需要 Bot 在目标群具有管理员或群主权限（用于禁言、踢人、撤回消息）
- **Python 依赖** - aiosqlite >= 0.19.0

## 安装方法

### 通过 AstrBot 插件市场安装（推荐）
```bash
在 AstrBot 控制面板 -> 插件市场 -> 搜索 "进群禁言" -> 点击安装
```

### 手动安装
```bash
# 1. 进入 AstrBot 插件目录
cd data/plugins

# 2. 克隆仓库
git clone https://github.com/nuomicici/astrbot_plugin_auto_ban_new

# 3. 安装依赖
pip install -r astrbot_plugin_auto_ban_new/requirements.txt

# 4. 重启 AstrBot
```

## 使用指南

### 基础配置流程

1. **访问 WebUI 管理界面**
   - 启动 AstrBot 后，可在 AstrBot 控制台进入插件管理页，点击"进群禁言"插件进入"可视化视图"（settings）
   - 或直接在浏览器访问 `http://localhost:6185/astrbot_plugin_auto_ban_new/pages/settings/index.html`

2. **刷新群列表**
   - 点击右上角"刷新群列表"按钮，加载 Bot 加入的所有群聊
   - 列表会优先显示 Bot 具有管理员权限的群聊

3. **选择群聊并配置**
   - 点击左侧群卡片进入配置页面
   - 调整禁言时长、提示消息、白名单关键词等参数
   - 点击"保存配置"使设置生效

4. **管理监控用户**
   - 在配置页面底部查看当前监控用户列表
   - 可手动移除不需要继续监控的用户

### 配置项说明

#### 基础管控开关与设置
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 群总功能开关 | 是否启用本群插件总功能（按群独立控制） | 默认关闭 |
| 首次禁言开关 | 新成员入群时是否立即执行初始禁言 | 默认开启 |
| 首次禁言时长 | 新成员入群时的初始禁言秒数 | 180 秒 |
| 后续监听开关 | 是否持续监控未解禁用户的发言，直到通过验证 | 默认关闭 |
| 后续禁言开关 | 监听中用户违规发言时是否执行递进禁言处罚 | 默认开启 |
| 撤回开关 | 是否自动撤回监听中用户的非白名单消息（仅对受监控用户生效） | 默认关闭 |
| 计次开关 | 是否统计违规发言次数并在超限时自动踢出 | 默认开启 |
| 自动踢出阈值 | 开启计次开关后，违规达到多少次自动踢出群聊 | 7 次 |
| 启用戳一戳解禁 | 是否允许戳一戳 Bot 快速解除监听 | 开启 |

#### 递进式禁言时长
| 违规次数 | 配置项 | 默认时长 |
|----------|--------|----------|
| 第 1-2 次 | ban_duration_1 | 180 秒（3 分钟）|
| 第 3 次 | ban_duration_2 | 180 秒（3 分钟）|
| 第 4 次 | ban_duration_3 | 600 秒（10 分钟）|
| 第 5+ 次 | ban_duration_4 | 3600 秒（1 小时）|

#### 消息模板与动态占位符
所有提示文本均支持以下动态占位符，支持在欢迎词及各违规提醒中自由排版并重复引用题目：
- `{question}` 或 `{验证题目}`：当前分配给该成员的随机验证题目内容（加减算式、乘除算式或自定义问答）
- `{random}` 或 `{随机内容}`：每次发信动态生成的随机字符（用于防止连续发送相同消息被 QQ/平台拦截去重）
- `{duration}` 或 `{禁言时长}`：本次处罚的禁言时长（秒）
- `{count}` 或 `{违规次数}`：当前累计违规次数
- `{threshold}` 或 `{踢出阈值}`：达到踢出的违规次数上限
- `{user}` 或 `{用户}`：被处理成员的 QQ 号码

#### 消息模板配置项
- **白名单关键词** - 发送包含该关键词的消息可解除监听（仅在关键词验证模式下生效，支持逗号或换行分隔）
- **自定义题库** - 自定义问答/诗词填空题库（每行一道题，格式为 `问题|答案`）
- **欢迎消息** - 新成员入群时发送的引导消息，支持插入 `{question}` 与 `{random}`
- **验证成功消息** - 用户回答正确或输入白名单关键词后的提示
- **戳一戳解禁消息** - 用户戳一戳 Bot 后的提示
- **踢出提示消息** - 用户达到违规阈值被踢出前的警告
- **违规提示消息** - 第 1-2 次、第 3 次、第 4 次、第 5+ 次违规时的不同提示，均支持使用 `{question}` 重复提醒当前题目内容

### 工作流程示例

```
新成员 A 加入群聊
    ↓
Bot 自动禁言 180 秒 + 发送欢迎消息（@新成员）
    ↓
新成员 A 发送消息（尝试发言）
    ↓
┌─ 包含白名单关键词？
│   ├─ 是 → 解除禁言 + 移除监控 + 发送成功提示
│   └─ 否 → 撤回消息（可选）+ 禁言 180 秒 + 发送第 1 次违规提示
│           ↓
│       违规次数 +1
│           ↓
│       ┌─ 达到踢出阈值？
│       ├─ 是 → 踢出群聊 + 移除监控
│       └─ 否 → 继续监控
│
或者
│
新成员 A 戳一戳 Bot
    ↓
解除禁言 + 移除监控 + 发送戳一戳解禁消息
```

## WebUI 界面说明

### 群列表面板（左侧）
- 显示所有 Bot 加入的群聊
- 群卡片包含：群头像、群名、群号、Bot 权限标识

- **消息模板区域** - 自定义各类提示消息文本
- **监控用户列表** - 查看当前监控用户，支持手动移除
- **操作按钮** - 保存配置、重置为默认

### 主题切换
- 点击右上角主题按钮可切换浅色/深色/自动主题
- 主题选择会自动保存到本地存储

## 注意事项

1. **权限要求**
   - Bot 必须具有群管理员或群主权限才能执行禁言、踢人、撤回消息操作
   - 如果 Bot 无权限，插件会记录警告日志但不会报错

2. **平台限制**
   - 插件仅支持 OneBot v11 协议（如 go-cqhttp、Lagrange、NapCat 等）
   - 不支持官方 QQ Bot、Telegram、Discord 等其他平台

3. **Bot 自身入群**
   - 插件会自动识别并忽略 Bot 自身的入群事件，不会对 Bot 自己执行禁言

4. **数据持久化**
   - 所有配置和监控数据存储在 `data/plugin_data/astrbot_plugin_auto_ban_new/auto_ban.db`
   - 定期备份数据库文件以防数据丢失

5. **性能优化**
   - 群列表带有 90 秒缓存，减少 API 调用频率
   - 后台巡检任务每 5 分钟运行一次，不会频繁占用资源

## 常见问题

### Q: 插件加载后没有效果？
**A:** 检查以下几点：
1. Bot 是否具有群管理员权限
2. 群是否已在 WebUI 中配置并启用
3. AstrBot 日志中是否有报错信息

### Q: 如何批量启用所有群？
**A:** 目前需要在 WebUI 中逐个群配置。未来版本会添加批量操作功能。

### Q: 可以自定义更多违规阶段吗？
**A:** 当前版本支持 4 个阶段。如需更多阶段，可在 GitHub 提交 Feature Request。

### Q: 如何临时禁用某个群的监控？
**A:** 在 WebUI 中选择对应群聊，关闭"启用进群禁言"开关，然后保存配置。

### Q: 监控用户数据会自动清理吗？
**A:** 会。当用户主动退群、被踢出、或被后台巡检发现不在群内时，会自动从监控列表移除。
